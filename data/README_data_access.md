# Data access

The participant-level analytic dataset is not included in this repository because it contains confidential research data.

The analysis script expects a local SPSS file named `Nazari_Liver_Transplant_Clean.sav` in this directory, or a path supplied through the `ANALYSIS_DATA_FILE` environment variable.

Requests for access should be directed to the corresponding author and are subject to institutional approval, applicable consent and ethics restrictions, and an appropriate data-use agreement.
